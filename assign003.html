# Histogram

# Generate 50 random values from a standard normal distribution
Y <- rnorm(50)

# Replace any values outside the range -3.5 to 3.5 with NA
Y[Y < -3.5 | Y > 3.5] <- NA

# Create a sequence of x-values from -3.5 to 3.5 in increments of 0.1
# These values will be used to draw the normal density curve
x <- seq(-3.5, 3.5, .1)

# Calculate the standard normal density for each x-value
dn <- dnorm(x)

# Set the plot margins: bottom, left, top, and right
par(mar=c(4.5, 4.1, 3.1, 0))

# Create the histogram of Y
# breaks controls the histogram bins
# ylim sets the vertical axis from 0 to 0.5
# col makes the bars light gray
# freq=FALSE makes the y-axis density instead of frequency
hist(Y, breaks=seq(-3.5, 3.5), ylim=c(0, 0.5), 
     col="gray80", freq=FALSE)

# Add the normal density curve on top of the histogram
# lwd=2 makes the line thicker
lines(x, dnorm(x), lwd=2)
# Reset the plot margins to the default values used in the examples

2.c: Comparing ways of drawing them

Although the four datasets have nearly identical slopes, intercepts, R² values, and residual standard errors, the plots show very different relationships. The first dataset follows a fairly linear pattern, while the second has a curved relationship. The third is mostly linear but contains an influential outlier, and the fourth shows that one unusual point strongly affects the regression line. The summary statistics hide these differences in shape, outliers, and influential observations, while the plots make them immediately visible. The code used to demonstrate these differences is provided below.
