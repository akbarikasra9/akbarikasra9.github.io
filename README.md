One project included in this repository is the EPPS 6356 Data Visualization Assignment 4: 48-Hour Chart Hackathon.

The assignment uses the Happy Planet Index 2006–2025 public dataset to create:

1.  Variable-width column chart
2.  Table with embedded charts
3.  Bar chart
4.  Column chart

Supporting files include:
