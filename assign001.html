Interpretation

The article talks about how most textbooks on statistical methods and computer programs do not pay much attention to graphs. The majority of statisticians, programmers, analysts, and researchers believe numerical calculations are exact, while graphs are rough, that there is just one set of calculations constituting a correct statistical analysis for any particular kind of statistical data, and that inspecting the data is considered cheating whereas the performance of intricate calculations is virtuous.

These assumptions have negatively impacted data visualization due to those norms practiced, but the evidence states that computers should actually perform both calculations and graphs. Anscombe emphasizes the purposes of graphs, such as helping us perceive and appreciate broad features of the data and allowing us to look behind those broad features to see what else is present.

Methods such as simple linear regression and multiple linear regression are effective. However, without graphical analysis, numerical and statistical calculations are incomplete. Statistical analysis is necessary for integrating both calculations and graphs to validate models properly and identify hidden anomalies.

Chart Critique: CNN Poll of Polls — Trump Approval Rating Over Time

Original Visualization

Source: CNN Politics, CNN Poll of Polls: Trump Approval Rating Over Time. Accessed September 15, 2026.

What the Chart Shows

This visualization shows President Donald Trump’s approval and disapproval ratings for the past year through the use of CNN’s Poll of Polls. The Poll of Polls combines recent national polls that meet CNN’s reporting standards. The primary takeaway is that approval decreased over the period shown while disapproval increased.

What Works Well

The chart effectively demonstrates the overall direction of approval and disapproval for the past year. Using two distinct colors makes the approval and disapproval lines easy to differentiate, while the direct labels at the end of each line allow viewers to identify the most recent percentages without having to use a separate legend.

The time-series format also works well because it allows the viewer to follow changes in the ratings chronologically. The percentage labels on the y-axis and dates on the x-axis are relatively simple, which keeps the chart from becoming overly cluttered. The vertical line marking the most recent date is also useful because it draws attention to the latest results.

What Could Be Improved

Percentage Scale

One weakness of the chart is that the y-axis only displays approximately 35% to 65% rather than the full 0% to 100% percentage scale. Even though this makes smaller changes easier to see, it can additionally make changes in approval and disapproval appear visually larger than they would on a full percentage scale.

Poll of Polls Aggregation

Another weakness is that the Poll of Polls presents an average, which makes the overall trend easy to understand but hides some of the variation among the individual polls used to calculate it. A viewer cannot see from the chart alone how much the results differ between polling organizations or individual surveys.

Month Labels

Another limitation is the lack of consistent month labels along the x-axis. The chart only displays selected dates, which makes it more difficult to identify when changes in approval and disapproval occurred throughout the period. Showing each month, or using evenly spaced monthly labels, would make the timeline easier to follow and allow viewers to interpret changes more precisely.

How I Would Improve It

I would organize the individual national polls reported by CNN into monthly averages so viewers can see changes in approval and disapproval throughout the period more clearly. This provides additional information from the underlying polling observations while reducing the visual clutter that could result from displaying every individual poll separately.

I would also use a full 0% to 100% y-axis. This provides more context for the size of the differences between approval and disapproval and reduces the possibility that smaller movements will appear exaggerated. I would keep separate colors for approval and disapproval because this makes the two measures easy to compare.

I would also display each month consistently along the x-axis. The redesigned chart below provides more detail about the underlying polling results by month while still showing the overall direction of approval and disapproval over time.

click_load_more <- function(page) {

  result <- page$session$Runtime$evaluate(
    "
    (() => {
      const buttons = Array.from(document.querySelectorAll('button'));

      const button = buttons.find(
        b => b.innerText.trim().toLowerCase() === 'load more'
      );

      if (!button) {
        return false;
      }

      button.click();
      return true;
    })()
    ",
    returnByValue = TRUE
  )

  isTRUE(result$result$value)

  str_detect(

    "^disapprove"
  )

    names(trumppolls),
    "date"
  )
][1]

# 7. Create clean approval and disapproval variables
# ------------------------------------------------------------

trumppolls <- trumppolls %>%
  mutate(

    approval = parse_number(
      as.character(
        .data[[approve_col]]
      )
    ),

    disapproval = parse_number(
      as.character(
        .data[[disapprove_col]]
      )
    )
  )


# ------------------------------------------------------------
# 8. Convert CNN poll dates into R dates
# ------------------------------------------------------------

trumppolls <- trumppolls %>%
  mutate(

    poll_date = mdy(

      paste(

        str_extract(
          .data[[date_col]],
          "^[A-Za-z]+"
        ),

        str_match(
          .data[[date_col]],
          "^[A-Za-z]+\\s+(\\d{1,2})"
        )[, 2],

        str_extract(
          .data[[date_col]],
          "\\b\\d{4}\\b"
        )
      )
    )
  )


# ------------------------------------------------------------
# 9. Calculate monthly averages
# ------------------------------------------------------------

monthly_polls <- trumppolls %>%
  filter(
    !is.na(poll_date),
    !is.na(approval),
    !is.na(disapproval)
  ) %>%

  mutate(
    month = floor_date(
      poll_date,
      unit = "month"
    )
  ) %>%

  group_by(month) %>%

  summarise(

    approval = mean(
      approval,
      na.rm = TRUE
    ),

    disapproval = mean(
      disapproval,
      na.rm = TRUE
    ),

    number_of_polls = n(),

    .groups = "drop"
  )


# ------------------------------------------------------------
# 10. Convert monthly data to long format
# ------------------------------------------------------------

monthly_plot <- monthly_polls %>%

  select(
    month,
    approval,
    disapproval
  ) %>%

  pivot_longer(
    cols = c(
      approval,
      disapproval
    ),
    names_to = "rating",
    values_to = "percent"
  ) %>%

  mutate(
    rating = recode(
      rating,
      approval = "Approve",
      disapproval = "Disapprove"
    )
  )


# ------------------------------------------------------------
# 11. Monthly redesigned visualization
# ------------------------------------------------------------

ggplot(

    y = percent,

    group = rating

Overall

CNN’s visualization successfully communicates the overall direction of presidential approval and disapproval in a simple and readable format. Its direct labeling, limited use of color, and time-series design make the main pattern easy to identify.

However, the shortened percentage scale, the use of an aggregated Poll of Polls, and the limited number of month labels provide less detail about the underlying polling results and make some changes more difficult to interpret precisely.
